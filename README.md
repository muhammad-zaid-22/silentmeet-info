Single self-contained `index.html` (no build step) — deep-navy glassmorphic theme in the SilentMeet brand-blue palette. Edit it and push to `main` to update the live page.

## Custom logo

The header shows a built-in bell SVG by default. To use your own artwork, drop a
square **`logo.png`** (e.g. 256×256) into the repo root and push — the page loads it
automatically and hides the SVG fallback. No code changes needed.
